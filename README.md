# ヒロイン・チャンピオン

ヒロインをスカウトし、共に戦い、育て、進化させて、ジムとダンジョンを攻略しながらバトルチャンピオンを目指すブラウザRPGです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルド・サーバー不要)。

- 移動: 矢印キー / WASD / 画面の十字ボタン
- 戦闘ログはタップすると早送りできます。戦闘中の「速度」ボタンで表示速度を切り替えられます。
- セーブはブラウザの localStorage に保存されます(町に入ったときなどに自動セーブ)。

## ゲームの流れ

1. はじまりの町で最初のパートナー(ヒカリ / シズク / ワカバ)を選ぶ
2. 道路やダンジョンで野生のヒロインとバトルし、HPを削ってからスカウトカードを渡して仲間に誘う
3. レベルアップで技を覚え、一定のレベルで進化(最大3段階)
4. 4つのジム(草・水・雷・氷)でバッジを集める
5. 迷いの森・雷鳴の洞窟・氷結の塔・チャンピオンロードを踏破する(最下層のボスもスカウトできる)
6. セントラルリーグで四天王4人とチャンピオンに連勝して殿堂入り

## システム

- 10タイプの相性(炎・水・草・雷・氷・拳・魔・闇・光・無)
- ヒロイン27人(進化系統と伝説級のボスを含む)
- パーティは最大6人。それ以上はボックスへ送られる
- 控えのメンバーも経験値の半分を受け取る
- ショップの品揃えはバッジの数に応じて増える

## ヒロイン画像の登録

タイトル画面の「画像設定」、またはゲーム中の「画像」ボタンから、ヒロインごとに好きな画像を登録できます。

- 登録した画像は、バトル・図鑑・パーティ・殿堂入りなど、すべての画面の立ち絵に使われます
- 進化前と進化後には、それぞれ別の画像を登録できます
- 画像は長い辺が320pxになるよう縮小し、このブラウザ内(localStorage)にだけ保存します。サーバーへは送信しません
- 「戻す」で元のイラストに戻せます
